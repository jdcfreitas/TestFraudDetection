# Python Hello World

A simple Python hello world project.

## Requirements

- Python 3.x

## Project Structure

```
HelloWorldPy/
├── main.py          # Main entry point
├── README.md        # This file
└── .github/
    └── copilot-instructions.md
```

## Running the Project

Run the main script:

```bash
python main.py
```

Or using the virtual environment:

```bash
.venv/bin/python main.py
```

## Expected Output

```
Hello, World!
```
